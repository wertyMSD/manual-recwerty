# Capture modes

RecWERTY offers three capture modes:

- [Recording](grabacion.md) — Complete flow before, during, and after recording

### Full screen

Capture your entire monitor. If you have multiple monitors, select which one to use from the dropdown.

### Window

Select a specific window to record. RecWERTY automatically lists all visible active windows. Ideal for recording a single application without distractions.

### Custom region

Draw a rectangle on screen to capture only that region. A visual guide appears so you can adjust the exact area. Press **ESC** to cancel.

!!! tip "Which one to choose?"
    - **Full screen**: Great for general demonstrations.
    - **Window**: Perfect for showing a specific application.
    - **Custom region**: Useful for highlighting a specific area without distractions.
