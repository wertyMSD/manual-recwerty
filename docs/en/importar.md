# Import and process existing videos

You can import previously recorded videos to apply RecWERTY effects.

## Import Video Dialog

1. Click **IMPORT VIDEO & APPLY EFFECTS** from the main screen.
2. Select the video file.
3. Available options:
    - **Trim**: Cut the start and end of the video.
    - **Background**: Choose automatic, preset, or none.
    - **Voice-over recording**: Record narration over the imported video.

## Processing

The imported video goes through the same effects pipeline as a new recording (click effects, transitions, intro, audio enhancement).
