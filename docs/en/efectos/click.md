# Click effects

| Effect | Description |
|---|---|
| **Ripple** | Material Design expanding wave at click position |
| **Pulse** | Circular flash that pulses at the click point |
| **Sparkle** | Bright particles bursting on click |
| **None** | No visual effect |

!!! tip "Customization"
    Effect colors are extracted from your brand configuration if set.
