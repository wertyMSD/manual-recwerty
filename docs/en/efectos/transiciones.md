# Transitions

| Transition | Description |
|---|---|
| **None** | Direct cut |
| **Crossfade** | Classic dissolve |
| **Slide left** | Slide to the left |
| **Zoom in** | Zoom in effect |
| **Wipe left** | Wipe effect |
| **Circle reveal** | Circular reveal |
| **Glitch** | Digital glitch effect |
