# Polyphonic keyboard sounds

Sound system that plays variations based on:

- **Key type**: Letters, space, enter, backspace, modifiers, numbers, symbols, arrows.
- **Typing speed**: Adjusts volume based on how fast you type.
- **Multiple variations**: Avoids robotic sound with random samples.

!!! tip "Natural sound"
    Thanks to multiple variations per key type, the sound avoids the robotic effect and sounds natural, like a real mechanical keyboard.
