# Audio configuration

On the home panel:

- **Microphone**: Select input device.
- **System sound**: Record or disable system audio.
- **Voice enhancement**: Enable/disable studio processing.
- **Normalize audio**: Even out overall volume.
- **Click sounds**: Enable/disable mouse sounds.
- **Keyboard sounds**: Enable/disable typing sounds.
