# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| **Alt + R** | Stop recording |
| **Alt + Z** | Toggle manual zoom |
| **ESC** | Cancel zone selection |
| **Ctrl + Shift + R** | Start quick capture (global shortcut) |

Shortcuts are displayed on screen during recording.
