# Navigation sidebar

| Icon | Section | Description |
|---|---|---|
| 🏠 | **Home** | Main recording panel |
| 🎨 | **Brand** | Brand customization and presets |
| ⚙️ | **Settings** | General app configuration |
| 📋 | **Queue** | Render queue |
| ℹ️ | **About** | Application information |

## Top status bar

Displays:

- Active capture mode
- Recording status
- Available shortcuts (Alt+R to stop, Alt+Z for zoom)

!!! info "Shortcuts during recording"
    Shortcuts are shown in the interface during recording. See [Keyboard shortcuts](../atajos.md) for the full list.
