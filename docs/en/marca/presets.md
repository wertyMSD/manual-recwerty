# Brand presets

You can create multiple presets for different clients or projects:

- **Save preset**: Save the current configuration as a preset.
- **Load preset**: Switch between saved presets.
- **Import preset (`.recbrand`)**: Share presets as branded ZIP files.
- **Export preset**: Export a preset as a `.recbrand` file.

The app automatically applies the configured preset on startup.

!!! tip "Multiple clients"
    If you work with multiple clients, create one preset per client and switch between them depending on the project.
