# Interfaz principal

La interfaz de RecWERTY tiene un diseño oscuro tipo "Nothing" con acentos en rojo (#D71921).

Incluye un panel de navegación lateral y una barra de estado superior.

| Elemento | Descripción |
|---|---|
| [Panel de navegación](navegacion.md) | Sidebar izquierdo con secciones principales |
| [Barra de estado](navegacion.md#barra-de-estado-superior) | Modo de captura, estado y atajos |
