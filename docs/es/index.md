# Manual de RecWERTY para grabar la pantalla en Windows

RecWERTY sirve para grabar demos, tutoriales y recorridos de software en Windows sin pasar por un editor externo. Elegís qué capturar, grabás, procesás el resultado y exportás un video MP4 listo para compartir.

## Camino rápido

1. Instalá RecWERTY desde el instalador oficial o Microsoft Store cuando esté disponible.
2. Abrí RecWERTY desde el menú Inicio de Windows.
3. Elegí el modo de captura: **Pantalla completa**, **Ventana** o **Zona**.
4. Activá o desactivá micrófono, sonido del sistema, efectos y marca.
5. Iniciá la captura con **Win + Alt + C** o desde la pantalla principal.
6. Detené la grabación con **Alt + R**, **Win + Alt + C** o el control de detención.
7. Revisá el resultado, procesalo y exportalo como **MP4**.

!!! tip "Resultado esperado"
    Las grabaciones se guardan por defecto en `Documentos\RecWERTY\recordings`. Las capturas rápidas se copian al portapapeles y también se guardan en `Documentos\RecWERTY\snapshots`.

## Funciones confirmadas

- **Captura de pantalla**: pantalla completa, ventana específica o zona personalizada.
- **Control por atajos**: **Win + Alt + C** para iniciar/detener captura rápida, **Alt + R** para detener y **Alt + Z** para zoom.
- **Audio**: micrófono y sonido del sistema según tu configuración.
- **Snapshot**: captura de imagen al portapapeles y archivo en la carpeta de snapshots.
- **Marca**: panel para gestionar intros, endings, logos y presets.
- **Procesamiento**: cola con progreso visible para los trabajos de renderizado.
- **Exportación**: salida en formato MP4.

!!! note "Microsoft Store"
    El Store ID reservado es `9NLD6GX4L1R1`. El enlace público y el deep link se completan cuando la publicación esté disponible.

## Checklist rápido

- [ ] RecWERTY está instalado y abre desde Windows.
- [ ] El modo de captura elegido coincide con lo que querés mostrar.
- [ ] El micrófono y el sonido del sistema están como necesitás.
- [ ] La marca, intro o ending están configurados si el video los requiere.
- [ ] El video final se exportó como MP4.
- [ ] El archivo aparece en `Documentos\RecWERTY\recordings` o en la carpeta elegida.
