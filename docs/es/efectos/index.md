# Efectos y movimiento

RecWERTY incluye un sistema completo de efectos visuales que se aplican automáticamente a tu grabación.

| Efecto | Descripción |
|---|---|
| [Efectos de clic](click.md) | Ripple, pulse, sparkle |
| [Estela del cursor](cursor.md) | Comet trail, destello |
| [Partículas](particulas.md) | Sistema de partículas dinámicas |
| [Transiciones](transiciones.md) | Crossfade, slide, zoom, glitch |
| [Sonidos de teclado](sonidos-teclado.md) | Sonidos polifónicos por tipo de tecla |
