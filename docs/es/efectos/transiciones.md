# Transiciones

| Transición | Descripción |
|---|---|

| **Crossfade** | Disolvencia clásica |
| **Slide left** | Deslizamiento hacia la izquierda |
| **Zoom in** | Acercamiento |
| **Wipe left** | Barrido |
| **Circle reveal** | Revelado circular |
| **Glitch** | Efecto de falla digital |
