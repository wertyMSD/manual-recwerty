# Requisitos del sistema

| Componente | Requisito |
|---|---|
| **Sistema operativo** | Windows 10 u 11 (64 bits) |
| **RAM** | 8 GB mínimo (16 GB recomendado) |
| **GPU** | Recomendable para acelerar el procesamiento de video |
| **Disco** | 500 MB para la aplicación, más espacio para grabaciones |
| **Internet** | Necesaria para instalar y para descargar componentes si hacen falta |

## Procesamiento de video

RecWERTY usa FFmpeg para procesar y exportar videos. Si el componente hace falta, la app puede descargarlo automáticamente durante el flujo de uso.

!!! tip "Para usuarios finales"
    No necesitás instalar Python, ejecutar comandos ni modificar variables del sistema para usar el instalador oficial.
