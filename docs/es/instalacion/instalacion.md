# Instalación

## Camino rápido

1. Descargá `Setup_RecWERTY.exe` desde el canal oficial, o instalá RecWERTY desde Microsoft Store cuando esté disponible.
2. Abrí el instalador.
3. Seguí el asistente de instalación.
4. Buscá **RecWERTY** en el menú Inicio de Windows y abrilo.

!!! info "Canal recomendado"
    Las actualizaciones para usuarios finales se publican como nuevas versiones del instalador o por Microsoft Store/Partner Center. No necesitás ejecutar comandos ni actualizar desde dentro de la app.

=== "Microsoft Store"

    - Store ID reservado: `9NLD6GX4L1R1`.
    - El enlace público se completará después de publicar RecWERTY.
    - Las actualizaciones llegan desde Microsoft Store.

=== "Instalador oficial"

    - Usá `Setup_RecWERTY.exe` solo desde el canal oficial.
    - Al terminar, abrí RecWERTY desde el menú Inicio.
    - Si Windows muestra SmartScreen, revisá el origen antes de continuar.

## Dónde se guardan los datos

RecWERTY usa carpetas de usuario para guardar tu configuración y tus resultados:

- **Configuración**: `%APPDATA%\RecWERTY\`
- **Grabaciones**: `Documentos\RecWERTY\recordings\`
- **Presets de marca**: `Documentos\RecWERTY\brands\`
- **Snapshots**: `Documentos\RecWERTY\snapshots\`

## Si Windows muestra una advertencia

- Verificá que el archivo venga del canal oficial.
- Si SmartScreen aparece, revisá el publicador y continuá solo si confiás en el origen.
- Si la instalación falla por permisos, volvé a ejecutar el instalador como administrador.
