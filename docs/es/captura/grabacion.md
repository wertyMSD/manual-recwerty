# Grabación

## Camino rápido

1. Elegí **Pantalla completa**, **Ventana** o **Zona**.
2. Confirmá audio, efectos y marca.
3. Iniciá con **Win + Alt + C** o desde el botón principal.
4. Detené con **Alt + R**, **Win + Alt + C** o el control de detención.
5. Revisá el resultado y continuá al procesamiento/exportación.

!!! warning "Sin pausa durante la grabación"
    El flujo confirmado es iniciar y detener. Si necesitás interrumpir una toma, detenela y comenzá una nueva grabación.

## Antes de grabar

Configurá estas opciones desde Inicio y los paneles laterales:

- **Micrófono**: Seleccioná el dispositivo de entrada o desactivarlo.
- **Sonido del sistema**: Activá o desactivá la captura de audio del sistema.
- **Marca**: Aplicá intros, endings, logos y presets si corresponde.
- **Efectos de movimiento**: Clics, estela del cursor, partículas.

!!! info "Referencia visual planificada"
    Captura sugerida para esta sección: `docs/es/assets/capturas/02-modos-captura.png`, mostrando las opciones Pantalla completa, Ventana y Zona.

## Durante la grabación

- **Alt + R**: Detener grabación.
- **Alt + Z**: Activar/desactivar zoom manual.
- **Win + Alt + C**: Iniciar/detener captura rápida.
- El timer overlay muestra el tiempo transcurrido.

## Después de grabar

Aparece una ventana posterior a la grabación para revisar la toma:

1. **Vista previa**: Reproducí el video grabado.
2. **Opciones de fondo**: Elegí entre:
    - **Auto**: Fondo generado automáticamente desde el color del video.
    - **Predefinido (HD)**: Fondos premium predefinidos.
    - **Ninguno**: Sin fondo adicional.
3. **Conservar o eliminar**: Elegí si quedarte con la grabación o descartarla.

!!! tip "Procesamiento posterior"
    Si conservás la toma, RecWERTY la procesa y muestra el progreso en la cola. Consultá [Cola de renderizado](../procesamiento/cola-renderizado.md) para ver cómo seguir el estado.

## Salida esperada

- Video final: MP4.
- Carpeta predeterminada: `Documentos\RecWERTY\recordings`.
- Snapshots: portapapeles y `Documentos\RecWERTY\snapshots`.
