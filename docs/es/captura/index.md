# Modos de captura

RecWERTY ofrece tres modos de captura. Elegí el más pequeño que muestre lo necesario: cuanto menos ruido visual grabes, más claro queda el video final.

- [Grabación](grabacion.md) — Flujo completo antes, durante y después de grabar

## Camino rápido

1. Usá **Pantalla completa** si necesitás mostrar todo el escritorio.
2. Usá **Ventana** si el foco es una aplicación concreta.
3. Usá **Zona personalizada** si solo importa una parte de la pantalla.
4. Probá una grabación corta antes de hacer la toma final.

### Pantalla completa

Capturá todo el monitor. Si tenés múltiples monitores, seleccionás cuál usar desde el desplegable.

### Ventana

Seleccioná una ventana específica para grabar. RecWERTY lista automáticamente las ventanas activas visibles. Ideal para grabar una aplicación sin distracciones.

### Zona personalizada

Dibujá un rectángulo en pantalla para capturar solo esa región. Aparece una guía visual para que ajustes el área exacta. Presioná **ESC** para cancelar.

!!! tip "¿Cuál elegir?"
    - **Pantalla completa**: Ideal para demostraciones generales.
    - **Ventana**: Perfecto para mostrar una aplicación específica.
    - **Zona personalizada**: Útil para destacar un área concreta sin distracciones.

## Captura rápida

Usá **Win + Alt + C** para iniciar o detener una captura rápida aunque RecWERTY no esté enfocado. Durante una grabación, usá **Alt + R** para detener y **Alt + Z** para activar o desactivar el zoom.
