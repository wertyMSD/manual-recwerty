# Presets de marque

Vous pouvez créer plusieurs presets pour différents clients ou projets :

- **Sauvegarder le preset** : Enregistrez la configuration actuelle comme preset.
- **Charger le preset** : Basculez entre les presets sauvegardés.
- **Importer un preset (`.recbrand`)** : Partagez des presets sous forme de fichiers ZIP avec marque.
- **Exporter un preset** : Exportez un preset en fichier `.recbrand`.

L'application applique automatiquement le preset configuré au démarrage.

!!! tip "Plusieurs clients"
    Si vous travaillez avec plusieurs clients, créez un preset par client et basculez entre eux selon le projet.
