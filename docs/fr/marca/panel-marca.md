# Panneau Marque

1. **Logo** : Téléchargez le logo de votre entreprise (PNG, JPG). RecWERTY extrait automatiquement les couleurs dominantes.
2. **Nom de l'entreprise** : Le nom qui apparaîtra dans l'intro.
3. **Couleurs** : Primaire, secondaire et accent. Elles sont détectées automatiquement depuis le logo ou vous pouvez les ajuster manuellement.
4. **Typographie** : Sélectionnez la police pour les textes.
5. **Template d'intro** : Choisissez parmi :
    - **Logo Reveal** : Intro cinématographique de 3s avec lueur.
    - **Minimal Fade** : Fondu élégant de 1,5s.

## Boîte de dialogue Marque

Accessible depuis le panneau Marque. Inclut :

- Aperçu de l'intro animée.
- Ajustement manuel des couleurs avec sélecteurs.
- Téléchargement du logo par glisser-déposer.
- Configuration "The End" avec logo, email et téléphone.

!!! tip "Couleurs automatiques"
    En téléchargeant un logo, RecWERTY extrait automatiquement les couleurs dominantes, mais vous pouvez les ajuster manuellement si vous préférez.
