# Premiers pas

1. Ouvrez RecWERTY. Il s'ouvre en plein écran avec une interface sombre moderne.
2. Dans le panneau latéral gauche, sélectionnez **Accueil**.
3. Choisissez votre **mode de capture** : Plein écran, Fenêtre ou Zone personnalisée.
4. Configurez les options audio, de marque et d'effets depuis les panneaux latéraux.
5. Cliquez sur **LANCER L'ENREGISTREMENT**.

!!! success "Prêt"
    Vous enregistrez maintenant. Consultez la section [Enregistrement](../captura/grabacion.md) pour connaître toutes les options de capture.
