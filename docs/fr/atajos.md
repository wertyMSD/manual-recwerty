# Raccourcis clavier

| Raccourci | Action |
|---|---|
| **Alt + R** | Arrêter l'enregistrement |
| **Alt + Z** | Activer/désactiver le zoom manuel |
| **ESC** | Annuler la sélection de zone |
| **Ctrl + Shift + R** | Lancer la capture rapide (raccourci global) |

Les raccourcis sont affichés à l'écran pendant l'enregistrement.
