# Modes de capture

RecWERTY propose trois modes de capture :

- [Enregistrement](grabacion.md) — Flux complet avant, pendant et après l'enregistrement

### Plein écran

Capturez la totalité de votre écran. Si vous avez plusieurs moniteurs, sélectionnez celui à utiliser depuis le menu déroulant.

### Fenêtre

Sélectionnez une fenêtre spécifique à enregistrer. RecWERTY liste automatiquement les fenêtres actives visibles. Idéal pour enregistrer une application sans distractions.

### Zone personnalisée

Dessinez un rectangle à l'écran pour capturer uniquement cette région. Un guide visuel apparaît pour ajuster la zone exacte. Appuyez sur **ESC** pour annuler.

!!! tip "Lequel choisir ?"
    - **Plein écran** : Idéal pour les démonstrations générales.
    - **Fenêtre** : Parfait pour montrer une application spécifique.
    - **Zone personnalisée** : Utile pour mettre en évidence une zone précise sans distractions.
