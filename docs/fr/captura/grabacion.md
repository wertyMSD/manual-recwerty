# Enregistrement

## Avant d'enregistrer

Configurez ces options sur le panneau d'accueil :

- **Microphone** : Sélectionnez votre périphérique d'entrée ou désactivez-le.
- **Son système** : Activez ou désactivez la capture audio système.
- **Intro personnalisée** : Activez pour inclure une intro animée avec votre marque.
- **Effets de mouvement** : Clics, traînée du curseur, particules.

## Pendant l'enregistrement

- Une **icône dans la barre système** apparaît indiquant que vous enregistrez.
- **Alt+R** : Arrêter l'enregistrement.
- **Alt+Z** : Activer/désactiver le zoom manuel.
- Le chronomètre superposé affiche le temps écoulé.

## Après l'enregistrement

La boîte de dialogue **Post-Recording** apparaît :

1. **Aperçu** : Lisez la vidéo enregistrée.
2. **Options d'arrière-plan** : Choisissez parmi :
    - **Auto** : Arrière-plan généré automatiquement à partir de la couleur de la vidéo.
    - **Prédéfini (HD)** : Arrière-plans premium prédéfinis.
    - **Aucun** : Sans arrière-plan supplémentaire.
3. **Conserver ou supprimer** : Choisissez de garder l'enregistrement ou de le jeter.

!!! tip "Post-traitement"
    Si vous choisissez de le conserver, le processeur vidéo s'ouvre où vous pouvez ajuster les effets avant le rendu final. Voir [Traitement](../procesamiento/index.md) pour plus de détails.
