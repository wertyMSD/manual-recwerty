# Configuration audio

Sur le panneau d'accueil :

- **Microphone** : Sélectionner le périphérique d'entrée.
- **Son système** : Enregistrer ou non l'audio système.
- **Amélioration vocale** : Activer/désactiver le traitement studio.
- **Normaliser l'audio** : Uniformiser le volume général.
- **Sons de clic** : Activer/désactiver les sons de souris.
- **Sons de clavier** : Activer/désactiver les sons de frappe.
