# Panneau de navigation (barre latérale gauche)

| Icône | Section | Description |
|---|---|---|
| 🏠 | **Accueil** | Panneau principal d'enregistrement |
| 🎨 | **Marque** | Personnalisation de la marque et presets |
| ⚙️ | **Paramètres** | Configuration générale de l'application |
| 📋 | **File d'attente** | File de rendu |
| ℹ️ | **À propos** | Informations sur l'application |

## Barre d'état supérieure

Affiche :

- Mode de capture actif
- État de l'enregistrement
- Raccourcis disponibles (Alt+R pour arrêter, Alt+Z pour le zoom)

!!! info "Raccourcis pendant l'enregistrement"
    Les raccourcis s'affichent dans l'interface pendant l'enregistrement. Consultez la liste complète dans [Raccourcis clavier](../atajos.md).
