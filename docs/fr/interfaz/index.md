# Interface principale

L'interface de RecWERTY adopte un design sombre style "Nothing" avec des accents rouges (#D71921).

Elle comprend un panneau de navigation latéral et une barre d'état supérieure.

| Élément | Description |
|---|---|
| [Panneau de navigation](navegacion.md) | Barre latérale gauche avec les sections principales |
| [Barre d'état](navegacion.md#barre-detat-superieure) | Mode de capture, état et raccourcis |
