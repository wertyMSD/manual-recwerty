# Transitions

| Transition | Description |
|---|---|
| **Aucune** | Coupure directe |
| **Crossfade** | Fondu classique |
| **Slide left** | Glissement vers la gauche |
| **Zoom in** | Effet de zoom avant |
| **Wipe left** | Balayage |
| **Circle reveal** | Révélation circulaire |
| **Glitch** | Effet de panne numérique |
