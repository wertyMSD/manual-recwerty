# Effets de clic

| Effet | Description |
|---|---|
| **Ripple** | Onde expansive style Material Design à la position du clic |
| **Pulse** | Flash circulaire qui pulse au point du clic |
| **Sparkle** | Particules brillantes qui explosent au clic |
| **Aucun** | Aucun effet visuel |

!!! tip "Personnalisation"
    Les couleurs des effets sont extraites de votre configuration de marque si elle est définie.
